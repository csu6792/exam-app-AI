# 📖 閱讀測驗與學習指引系統 (Reading & Quiz System)

本專案是一個網頁打造的**輕量化、跨平台學習應用程式**。

---

## ✨ 核心功能介紹 (Core Features)

### 1. 📚 智慧書架與 PDF 閱讀器 (Smart Bookshelf & PDF Reader)
系統內建客製化的 PDF 閱讀體驗，專為行動裝置優化：
* **核心：** 支援動態加載並解析 PDF 學習指引文件。
* **觸控手勢：** * 支援**雙指縮放 (Pinch-to-Zoom)**，動態計算畫布比例，文字放大不失真。
  * 支援**左右滑動 (Swipe)** 翻頁功能，提供如實體書般的閱讀體驗。
* **智慧進度追蹤：** 系統會透過自動記憶每本書的最後閱讀頁數與完成百分比，並即時顯示於書架封面。

### 2. 📝 動態模擬測驗系統 (Dynamic Mock Quiz System)
高度彈性的題庫驅動測驗引擎：
* **多題庫整合：** 自動解析並加載多個題庫（如初級、中級等），使用者可自由勾選要測驗的範圍。
* **隨機抽題與計時：** 支援自訂抽取題數，並具備測驗即時計時器，精準記錄作答耗時。
* **即時批改與深度解析：** * 提交試卷後，系統會自動比對答案並給予視覺化反饋（正確標綠、錯誤標紅）。
  * **專屬解析卡片 (Explanation)：** 每道題目下方會動態展開解析區塊，幫助使用者釐清錯誤觀念。
 
### 3. 📝 AI動態模擬測驗系統 (AI Dynamic Mock Quiz System)
* **多題庫整合：** AI自動出題。


### 4. Web App
支援App應用：
* **可安裝性 (Installable)：** 支援加入手機主畫面（Add to Home Screen），無瀏覽器外框，享受全螢幕 App 體驗。
* **網路優先快取 (Network-First Cache)：** 在無網路狀態下依然能開啟已快取的題庫與書本。
* **版本更新：** * 
  * 背景自動下載新版核心。
